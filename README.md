# Kafka Spring Stream — Class-Based Configuration

Kafka event streaming with Spring Boot using class-based configuration (as opposed to YAML-based config).

## Tech Stack

- **Framework:** Spring Boot, Spring Cloud Stream
- **Messaging:** Apache Kafka
- **Language:** Java
- **Build:** Maven

## Features

- Kafka producer and consumer setup
- Class-based Spring configuration (no YAML)
- Event-driven message processing

## Getting Started

```bash
# Start Kafka (Docker)
docker-compose up -d

# Run the application
mvn spring-boot:run
```
